Employee Directory

A company directory built over a legacy Microsoft Access database, sorted by department and hierarchy, with birthdays and work anniversaries on the front page.

An internal employee directory built on top of a legacy Microsoft Access database, which kept working the whole time. Employees are grouped by department and ordered by the real reporting hierarchy, and department heads and supervisors get a watermark on their cards.

The homepage celebrates everyone with a birthday or work anniversary this month, with extra emphasis on today’s. An advanced search filters by department, title, hire date and supervisor status, and any set of results exports to CSV.

~ highlights ~

  • Management commands to parse and import employee records from the legacy database
  • Syncs company events from SharePoint
  • Custom themes and a lightweight analytics middleware
  • A demo seed command, so the public version runs without real employee data
