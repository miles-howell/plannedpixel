02 / The workshop

Featured projects

Machine learning

NEW

Bridge-Crossing RL Sim

Hierarchical reinforcement learning in a grid world. A manager agent picks sub-goals, a worker agent walks there, and together they learn to fetch a log, build a bridge and get home. A “profit-sharing” reward keeps their goals aligned.

  • Python
  • PyTorch
  • Django
  • Web Workers

Security tooling

NEW

Vixxing

Caller verification for IT help desks. Before anyone resets a password or MFA, the caller reads a live 6-digit TOTP code off their phone. Facts leak. Possession doesn’t.

  • Django
  • PyOTP
  • TOTP
  • Microsoft Graph

03 / About

Understand it at the core, then build.

In high school I wrote a single-neuron network and reworked Karpathy's min-char-rnn to show off to classmates. I also co-led the programming club and consulted on my state's first high-school cybersecurity curriculum.

In college I spent two years on computer science and math, and started the ML/AI Special Interest Group. There were no undergraduate ML courses yet, so we broke the topics down in plain English, with no high-level libraries.

These days I run Planned Pixel Studio, and on my own time I experiment at the edges of AI research, like agents that learn to share profit. I think there are far more interesting, world-altering things to do with AI than chatbots.

Partners: Makoons Technologies for robust, scalable engineering, and Primagery for CRM, identities and brands.
